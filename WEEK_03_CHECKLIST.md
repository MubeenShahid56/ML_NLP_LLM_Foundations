# WEEK 03 — MACHINE LEARNING, NLP & LLM FOUNDATIONS

Use this checklist to track the tasks from the supplied Week 03 Checklist document.

## 1. Machine Learning — Text Classification

- [ ] Import the required libraries from scikit-learn.
- [ ] Create a small text dataset with corresponding labels.
- [ ] Convert text into numerical features using CountVectorizer or TF-IDF.
- [ ] Split the dataset into training and testing sets.
- [ ] Train a text classification model.
- [ ] Generate predictions for new text.
- [ ] Evaluate the model using accuracy and a classification report.
- [ ] Explain the difference between training and inference.

## 2. Natural Language Processing — Text Preprocessing

- [ ] Implement a text-cleaning function in Python.
- [ ] Remove unnecessary whitespace.
- [ ] Convert text to lowercase where appropriate.
- [ ] Remove punctuation where appropriate.
- [ ] Test the preprocessing function using multiple sentences.
- [ ] Explain why text preprocessing is useful.

## 3. Tokenization

- [ ] Install and import the required tokenizer libraries.
- [ ] Load a pretrained tokenizer such as BERT's tokenizer.
- [ ] Convert a sentence into tokens.
- [ ] Convert tokens into token IDs.
- [ ] Decode token IDs back into text.
- [ ] Compare token counts for two different tokenizers.
- [ ] Explain special tokens and subword tokenization.

## 4. Embeddings and Semantic Similarity

- [ ] Load a sentence-transformer model.
- [ ] Generate embeddings for multiple sentences.
- [ ] Calculate cosine similarity between two sentences.
- [ ] Compare semantically similar and unrelated sentences.
- [ ] Interpret the similarity scores.
- [ ] Explain the difference between word counts and semantic embeddings.

## 5. Semantic Search

- [ ] Create a small collection of text documents.
- [ ] Generate and store document embeddings.
- [ ] Convert a user query into an embedding.
- [ ] Calculate similarity between the query and documents.
- [ ] Rank documents by similarity score.
- [ ] Display the most relevant documents.
- [ ] Test the search system using at least three different queries.

## 6. Code Quality and Submission

- [ ] Organize the implementation into clearly named sections or functions.
- [ ] Use meaningful variable and function names.
- [ ] Run the code from beginning to end without unhandled errors.
- [ ] Add comments where they clarify important logic.
- [ ] Capture screenshots or output evidence.
- [ ] Prepare a README with setup and execution instructions.
- [ ] Submit the source code and required evidence.
